# Semester 1 — Software Architecture & Design

## Theme

Learn to think like a software architect.

The objective of this semester is not to memorize architecture patterns.

The objective is to understand *why* architectural decisions are made, what tradeoffs they introduce, and how they affect software over time.

---

## Learning Objectives

By the end of this semester I should be able to:

- Explain architectural tradeoffs.
- Design maintainable backend systems.
- Apply architectural patterns intentionally.
- Communicate architecture through diagrams and documentation.
- Produce Architecture Decision Records (ADRs).
- Evaluate architecture based on quality attributes.

---

## Primary Project

Arena Simulator Backend

Every topic learned should be evaluated against this project.

---

## Primary Deliverables

- Architecture Overview
- Domain Model
- Initial ADR collection
- Capstone Architecture Review
