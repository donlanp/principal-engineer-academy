# Module 1 — Foundations of Software Architecture

**Semester:** 1  
**Estimated Duration:** 2–3 Weeks  
**Difficulty:** ★★☆☆☆

---

# Objective

Develop a strong understanding of the foundational principles of software architecture.

By the end of this module, I should be able to explain *why* architecture exists, evaluate architectural decisions through trade-offs, and communicate architectural concepts clearly to other engineers.

---

# Learning Objectives

By the end of this module I should be able to:

- [ ] Explain what software architecture is.
- [ ] Explain why software architecture matters.
- [ ] Define quality attributes.
- [ ] Explain architectural characteristics.
- [ ] Explain coupling and cohesion.
- [ ] Evaluate simple architectural decisions.
- [ ] Identify architectural trade-offs.

# Topics

## Topic 1 — What is Software Architecture?

### Questions

- What is software architecture?
- Why does architecture exist?
- What decisions belong to architecture?
- Can architecture emerge naturally?
- What decisions are expensive to change later?

## Topic 3 — Coupling vs Cohesion

Understand:

- Tight vs Loose Coupling
